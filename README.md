# Anne Heloísa Brand

Landing page da boutique Anne Heloísa Brand (moda feminina, Tibiri, Santa Rita-PB).

- `index.html`: página completa (intro do logo + landing)
- `img/`: fotos tratadas (3:4) e logo em camadas
- `vid/`: vídeos do carrossel
- `og-image.jpg`: capa da prévia do link (1200x630)

Links da loja online, WhatsApp, endereço e categorias ficam no objeto `CONFIG` no fim do `index.html`.

Feito por Logotop Design.
